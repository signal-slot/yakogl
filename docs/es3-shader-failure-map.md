## 1. What is known per subgroup, and what is not

**No per-case result file exists in the repository for the GLES3 run.** §1r's
logs stayed in a worktree's `build/g3-396d667a/` and were never committed
(`RESULTS.md:1597-1598`). `docs/board-sessions/am62p-gles3-percase.md` tried
to produce the per-case list and got no result (`:5-13`, "Per-subgroup
first-message table: Not available", `:129-132`). So per-subgroup failure
counts are not available. This document uses only three sources of
per-subgroup information, and does not estimate beyond them:

1. **Exact by group from a bucket.** R-work `:989` splits the 1,483 bucket into
   builtin_functions 1,461 and builtin_variable 22. R-bucket `:1516` (103)
   names only shaders.derivate.
2. **Exact zero from an image with no failure.** An image's fail count bounds
   the fail count of every subgroup it ran. The image counts include cases
   outside the mustpass: image 7 reports 816 + 1,762 = 2,578 results, against
   1,949 mustpass names in its four subgroups (1,539 + 29 + 41 + 340). That
   makes them upper bounds. An image with 0 fails therefore proves 0 mustpass
   fails for each of its subgroups.
3. **Upper bounds from image fail counts.** Where an image holds only shaders
   subgroups, its fail count is an upper bound for their sum.

Image 6 (`RESULTS.md:1557`, 96 fails) also ran primitive_restart, rasterization,
rasterizer_discard, read_pixels, samplers and shader_api. Their mustpass fails are
0 + 21 + 51 + 24 + 0 + 0 = 96 (R-group `:1480-1485`). That leaves 0 for
shaders.arrays. Image 18 (`:1569`, 516 fails) also ran state_query (63 mustpass
fails, `:1487`) and texture.compressed (count not split from texture's 2,612).
So texture_functions + uniform_block ≤ 516 − 63 = 453.

The whole group: 20,616 mustpass cases = 18,385 pass + 2,231 fail + 0 n/s
(R-group `:1486`). Of the 2,231 failures, 1,461 + 22 + 103 = 1,586 are tied to
a subgroup by a bucket. The other **645 are not attributed** to any subgroup
by any file in the repository.

## 3. Root causes ranked by AM62P fail count

Only firm counts are ranked. The order of the unattributed 645 is not known.

1. **Integer colour render targets (missing GL API, then back end): ≥ 1,586.**
   1,461 builtin_functions + 22 builtin_variable (R-work `:989`, bucket
   `:1501`, CAUSE SHOWN) + 103 derivate (`:1516`, RGBA32UI FBO, read from
   es3fShaderDerivateTests.cpp:732). Example:
   `builtin_functions.common.round.float_highp_fragment`. The GL half is done
   on the host (item int-rt-gl, `tests/es3_int_rt.rs`). The back-end halves are
   int-rt-pvr, int-rt-v3d and int-rt-gc. shaders.precision's R32I/R32UI
   renderbuffers probably depend on the same gap (not shown).
2. **texture_functions: integer/depth upload, shadow and 3D-bias refusals,
   2D-array sampling: ≤ 453 (shared with uniform_block); exact count unknown.**
   Buckets `:1506`, `:1512`, `:1514`, `:1515`. Plan items: sized-formats-gl
   (done, GL core), formats-pvr, pvr-shadow, pvr-2darray.
3. **Unattributed rest: 645 = 2,231 − 1,586.** By image bound: img 7 rest
   (conditionals, constant_expressions, and builtin_functions/builtin_variable
   cases beyond the bucket) ≤ 279. Img 8 rest ≤ 225. Img 15 ≤ 71. Img 16
   (random: "Image comparison failed", wrong result) ≤ 32. Img 14 (operator,
   trunc refusal per `:1512`) ≤ 24. Img 9 ≤ 16. Img 18 (texture_functions,
   uniform_block) ≤ 453. These bounds overlap item 2 and sum to more than 645.
   They locate the failures; they do not count them.
4. **Exactly zero:** arrays, loops, matrix, metamorphic, negative, struct,
   switch, swizzle_math_operations, swizzles, operator.angle_and_trigonometry
   and the binary_operator subgroups in images 12 and 13. That is 308 + 579 +
   2,646 + 6 + 12 + 89 + 173 + 544 + 648 = 5,005 cases outside operator, plus
   the operator subgroups of images 12 and 13.
