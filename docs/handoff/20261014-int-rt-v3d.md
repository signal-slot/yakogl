  mesa-26.2.1-full`): `vir_emit_tlb_color_write` (`nir_to_vir.c:1974-1977`)

  `tlb_config_32b` (0 << 6); the pinned words lost 0x40 (0xffffff3f for RT 0

  42`) does return INT for a pure integer format, NORM for sRGB, NONE
  otherwise, so the clamp rows stand. The other `nir_to_vir.c`,
  `v3dx_format_table.c` and `v3dx_rcl.c` lines cited by this item match
  26.2.1; `v3d_tlb_clear`'s packing is `v3dx_draw.c:1706-1769`.
