# One rule per line, TAB-separated:  id  job-regex  kind  pattern  note
#   sub       pattern "REGEX => REPLACEMENT", applied to both lines before comparing
#   intsat    paired lines matching REGEX (group v) may differ where one side holds
#             INT_MIN and the other INT_MAX, 0 or INT_MIN
#   delta:N   paired lines matching REGEX may differ by exactly N in group v
#   line      lines matching REGEX may differ in any way
# Everything else that differs is unexpected. Keep this list short: each rule
# hides a class of differences, say why it is safe.

port-log-nonascii	.	sub	^log #\d+[:+] ;; (?:\\x[89a-f][0-9a-f]|\?) => ?	the port logs bytes >= 0x80 of shader sources / names as "?" (debug log text only)
x86-float-to-int-get	.	intsat	^~glGetIntegerv\(0x(?:2a00|8038|8005|c22|b21|b70|b73|80aa)\) data=\[\d+\](?P<v>.*)$	glGetIntegerv of float state outside the int range or NaN: C (int)f is undefined; x86 returns INT_MIN, aarch64 and Rust saturate (NaN -> 0)
