# rows `test ... (--lib, every test but the mali:: ones ...)` and

# that failed with this list: a failing test that is not here turns the row

#           targets, the Mali feature set) or tests-es2 (the same with
#           report-es2)
#   target  the cargo target (yakogl for the library, else the file name)
#   issue   the issue of the defect, `#<number>` (`#TODO-<name>` until it has one)
