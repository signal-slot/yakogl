#      function (framework/egl/wrapper/eglwInitCore.inl, through

#      libGLESv2.so.2 (framework/opengl/wrapper/glwInitES20.inl, through
#      egluGLContextFactory.cpp's DynamicFuncLoader), unless the display has
#      EGL_KHR_get_all_proc_addresses; extensions go through eglGetProcAddress.
