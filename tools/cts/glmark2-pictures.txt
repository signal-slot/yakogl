#
#   <column> | <scene info string> | <the text after "glmark2-picture: <scene>: ">
#
# The column is the board the run was made on (am62p, pi4, imx8mp), or host (the host
# harness, tools/hostharness/glmark2). The value is a glmark2 image's picture line
# (driver/docs/glmark2.md, "The picture value"); `common-tally.py --gm-picture-lines
# <console> <column>` prints a console's lines in this form. A board's picture is judged
# against the column of that board name: each probe and the mean must be within the
# tolerance (levels per channel) of the reference, the size must be the same, and an
# all-black picture is a failed cell where the reference is not black. crc16 is read, not
# judged: it is named when it differs. A scene with no line in the board's column is
# "no reference" (an amber cell), so a column is added only from a board run that was
# looked at, never copied from another board.
#
# host: the host harness draws nothing (tools/hostharness/glmark2/README.md), so every
# scene is black by design: the probes are 000000ff (the harness sets alpha to ff), the
# crc16 and crc16q are those of an all-zero 40x30 RGB grid, and the mean is 0 0 0. This
# column checks the parser and the table against the harness; it is not a picture of what
# a board draws, and no board is judged against it.
