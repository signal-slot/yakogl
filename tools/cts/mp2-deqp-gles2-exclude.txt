# reason; tools/cts/mp2-deqp-list-check.sh enforces it.
#
# Limits (src/vivante/profile.rs, GCNANOULTRA31_VIP2_ST :138 against the
# i.MX8MP's GC7000UL :101): instructions 512, temp registers 64, constants 320,
# varyings 16, streams 16 and non_power_of_two are the same on both parts, so
# no shader, texture or varying limit case is excluded. The only profile
# difference that reaches GLES2 is wideline_triangle_emu: true (line_width_range
# [1,1] until Q11), so the wide-line cases are listed here as pending Q11 and
# move back into the run when Q11 decides.
#
# Arena (128 MiB, boards/stm32mp257f_dk_stm32mp257fxx_a35.conf): the full tree
# fits (74.2% of the runner's window, the dk-image-budget study); the conf
# only says the 2048x2048 mipmap uploads "may" end in GL_OUT_OF_MEMORY, with
# no case named, so no group is excluded for memory until a DK run names one.
