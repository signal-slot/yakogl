# Cause-family rules for the AM62P dEQP-GLES3 not-pass list (read by
# tools/cts/gles3-triage.py --families). One rule per line, tab separated:
#   <family-id> TAB <comma-separated case globs> [TAB <message regex>]
# Globs (fnmatch, case sensitive) match the full case name; the optional regex
# (re.search) must also match the row's message. The first matching line wins,
# so the specific rules come first. A NoResult row has an empty message, so a
# rule with a regex never matches it; those rows are assigned by glob alone.
# Names follow RC1-RC18 of docs/es3-cts-failures.md (AM62P section) and the
# investigations; each family says what it rests on. "host-done" means built
# and pinned on the host, awaiting the board rerun. No rule is a guess: a
# group no document names is 'uninvestigated-<group>'.
#
