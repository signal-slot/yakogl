# glmark2-llvmpipe-ref.txt -- the picture values of glmark2-es2's 33 default scenes at
# 800x600 drawn by Mesa's llvmpipe on the host: a HOST REFERENCE, not a board result,
# and not a column of tools/cts/glmark2-pictures.txt (no board is judged against it
# by the gate). It is kept so that a board session (issue #17, the i.MX8MP by-eye
# check) has the llvmpipe probes in the tree instead of in a gitignored records/
# directory.
#
# Provenance: tools/cts/glmark2-host-ref.sh at yakogl 35c98f25 (2026-11-25), all 33
# scenes, 33 ok, 0 failed; glmark2 22c527cb0556f3a1ac4445aaa52cc532760928d5 (the
# script's COMMIT=) + tools/cts/glmark2-host-ref.patch sha256
# 8190dec8736eb1cff88a530fc62a897e98c800cacce10decc3e5f7a57f9fe998; Mesa 26.2.1 built
# by the script (llvmpipe, softpipe), GL_RENDERER llvmpipe (LLVM 21.1.8, 256 bits),
# GL_VERSION OpenGL ES 3.2 Mesa 26.2.1; Linux x86_64.
#
# Format: the line format of tools/cts/glmark2-pictures.txt with the column name
# llvmpipe, one line per scene in that table's scene order (glmark2-host-ref.sh --list):
#   llvmpipe | <scene info string> | <the text after "glmark2-picture: <scene>: ">
# No "tolerance" line: readers use their default of 8 levels per channel. Probes are
# RGBA8888 (alpha ff, or the scene's own alpha); a board's RGB565 probes have alpha 00
# and only R, G and B are compared. Read it with
#   tools/cts/common-tally.py --gm-pictures <console|run dir> llvmpipe --table tools/cts/glmark2-llvmpipe-ref.txt
#   tools/cts/glmark2-photo-probes.py <screenshot.png> ... --compare tools/cts/glmark2-llvmpipe-ref.txt llvmpipe '<scene>'
# Expect differences that are not defects: every animated scene ends on the pose its
# own clock reached (glmark2-host-ref.sh, "Animated scenes"), and llvmpipe is not a
# GPU. The [texture] tl values in particular are a pose-sensitive reference: the
# probe sits near the cube's edge, so a renderer with other frame times ends on
# another pose and tl can read the background (000000); a pose-matched llvmpipe
# value comes from tools/cts/glmark2-host-pose.sh at the board's ms per frame.
#
# Regenerate (records/ is gitignored; replace <sha8> by the yakogl commit):
#   tools/cts/glmark2-host-ref.sh --out records/host/gmref-<sha8>
#   tools/cts/glmark2-host-ref.sh --list | cut -f1 | while read -r s; do grep -a 'glmark2-picture:' records/host/gmref-<sha8>/$s.log | tail -1; done > records/host/gmref-<sha8>/console.txt
#   python3 -I tools/cts/common-tally.py --gm-picture-lines records/host/gmref-<sha8> llvmpipe | grep '^llvmpipe | '
