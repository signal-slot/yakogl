BOARD_HOST=user@host of the board`; the variable can only be given in the
command line, which needs approval. So `board.sh` never touched the board: no staging, no
tryboot, no reboot. Recoveries 0, reboots 0, GL clients 0 — nothing ran, so
these zeros say nothing about the GPU.
