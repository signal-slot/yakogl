# The common set: the five images every board runs first, from its bootloader
# (driver/docs/one-method.md; the user's order of 2026-10-03, with cluster
# joining on 2026-10-07). One image per
# row, the form of baseline-tree.txt: each row is "# image <LABEL>: ..." and
# then one line, and '#' and blank lines are skipped. tools/board.sh tree names
# each row by its label (TREE_IMAGE_DIR=<img-dir>: <img-dir>/<LABEL>/zephyr/zephyr.bin);
# the line under the label is what tools/cts/common-images.sh builds for it:
#   glmark2      driver/samples/zephyr/glmark2, its default benchmark set
#   slint        driver/samples/zephyr/slint, the window shown by a copy where
#                the board copies (Pi 4, i.MX8MP) and scanned in place on the
#                AM62P (board_show() flips the DSS plane to the window)
#   slint-view   the same with CONFIG_YAKOGL_BOARD_SCANOUT_VIEW=y: the window is
#                a view into the scan-out buffer (on the Pi 4 and the i.MX8MP;
#                the AM62P's board layer has no view and ignores the option,
#                so there the row is the same copy-free image as SO:
#                docs/investigations/am62p-scanout-view.md)
#   cluster      driver/samples/zephyr/cluster, the AGL cluster sample: the
#                agl-slint-cluster UI on the no_std Slint workspace, animating
#                for CONFIG_YAKOGL_BOARD_ANIMATE_S (60 s) at the board's panel
#                size (1024x600 AM62P, 1280x800 i.MX8MP, 1920x720 Pi 4) and
#                checking the result (its PROBES record is the verdict)
#   gl_test      the board's gl_test sample with its default case list (gl_test
#                on the AM62P, gc_gl_test on the i.MX8MP, v3d_gl_test on the Pi 4)
# Run it with tools/cts/cts-common.sh <board> build|run|tally (tools/cts/README.md).

glmark2
# image SO: slint, view off
slint
