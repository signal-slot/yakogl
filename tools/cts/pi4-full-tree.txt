# The whole dEQP-GLES2 tree for the Raspberry Pi 4 (driver/samples/zephyr/deqp)
# in 29 images, one CONFIG_DEQP_CASE per line, the format of am62p-full-tree.txt
# (blank lines and '#' lines are skipped, so am62p-deqp-images.sh reads it too).
# Each line is preceded by "# image <LABEL>: <mustpass names it selects>", the
# label the Pi 4 records and RESULTS.md use (record_SW<n>_<LABEL>.txt).
# Lines 1-27 are sweeps 28 and 29's filters unchanged; DR and XT select the
# 113 mustpass names those 27 never did (draw.* 101, clip_control 8,
# debug_marker 3, multisampled_render_to_texture.readpixels 1). Every one of
# the 17165 names of gles2-mustpass.txt is selected by exactly one line.
#

# (-DEXTRA_CONF_FILE=texture-2048.conf: 64 MiB carve-out, 24 MiB of tiled
# copies); without it the 2048x2048 draws are refused by the tiled-copy
# budget (sweep 29). Every other image uses boards/rpi_4b.conf as it is.
