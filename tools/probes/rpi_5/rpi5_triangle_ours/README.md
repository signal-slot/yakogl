# rpi5_triangle_ours

`rpi5_triangle` (M5) with our 7.1 online compiler's pass-through VS and
interp_color FS (`tools/v3d/tri-shaders71/ours_passthrough_interp_color.h`,
regenerated by `tests/v3d71_tri_shaders.rs`) instead of Mesa's. It has no
sources of its own: `CMakeLists.txt` takes `../rpi5_triangle/`'s sources
(`probe.cmake` with `RPI5_TRI_SHADERS=ours`), board overlay and `prj.conf`
(this directory's `prj.conf` is an empty fragment merged after it).

```sh
west build -p always -b rpi_5 -DYAKOGL_WERROR=ON -d build/rpi5_triangle_ours yakogl/tools/probes/rpi_5/rpi5_triangle_ours
```

What it does, its console, the verdict line (`v3d_triangle: PASS (...;
shaders ours)` or `v3d_triangle: FAIL (...; shaders ours)`) and how to run
it: `../rpi5_triangle/README.md`.

Verdicts: `../rpi5_triangle/verdicts.sh <console.log>` also reads this
image's `shaders ours` log (see "Verdicts" in `../rpi5_triangle/README.md`).
