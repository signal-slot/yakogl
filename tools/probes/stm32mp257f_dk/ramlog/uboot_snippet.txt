# U-Boot hush commands of the RAM-log save step (one command line).
# Lines starting "# " are comments; the runner puts the one command line
# below into its own variable and runs it from its hook before ST's boot.
# Variables (set by the runner, none by this file):
#   yako_ramlog_addr  the ring's DDR address (the image's Kconfig address)
#   yako_ramlog_size  bytes to save: 32 (header) + the ring's data size
#   boot_instance     ST's U-Boot variable for the device number, the one
#                     the runner's yako_mmc already loads from
#   yako_part         the bootfs partition (ext4; the runner stages under
#                     /boot/yakogl, which U-Boot sees as /yakogl)
# The file is written only when the magic is there; mw.l afterwards clears
# the magic so a later boot does not save the same ring again. Without the
# magic it says so ("yakogl-mp2: ramlog no ring at <addr>") and writes
# nothing, so U-Boot's console always shows which of the three it was. On the
# DK that is every boot: its warm reset does not keep DDR (README.md "Limit").
if itest.l *${yako_ramlog_addr} == 0x474C4B59; then if ext4write mmc ${boot_instance}:${yako_part} ${yako_ramlog_addr} /yakogl/ramlog.bin ${yako_ramlog_size}; then echo yakogl-mp2: ramlog saved; else echo yakogl-mp2: ramlog write failed; fi; mw.l ${yako_ramlog_addr} 0 1; else echo yakogl-mp2: ramlog no ring at ${yako_ramlog_addr}; fi
