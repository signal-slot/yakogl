# Sources a generator lists but no table can hold: the compiler refuses them.
#
# check_gl_test_blobs.py needs this list to tell the two absences apart. A
# source listed in a generator's inputs with no row in that generator's table
# is normally STALENESS -- somebody added it and never regenerated -- and that
# is what the check exists to catch, because it does not fail at build time, it
# fails on a board as a missing blob. These are the other thing: the source is
# listed, the generator ran, and the compiler would not build it.
#
# Established on 2026-09-22, not assumed: every entry here was also refused by
# the Vivante generator, which is a different compiler on a different tree
# (etna_shc/glslang vs pco_shc). The four es100/matattr* sources, absent from
# BOTH tables at that date, compiled cleanly for Vivante -- which is how they
# were identified as staleness rather than as members of this list.
#
# Empty since the Qt shaders left the tree (#1509): pco_shc builds every source
# the list names.
#
# An entry here that gains a row is also an error: the list has rotted and the
# check says so, so this cannot quietly become a list of excused failures.
