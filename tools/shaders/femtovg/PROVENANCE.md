# Provenance of tools/shaders/femtovg/

## Version

Both samples build **femtovg 0.26.0** (crates.io `femtovg-0.26.0`) with
`examples/nostd/femtovg-0.26.0-nostd.patch` applied
(`NOSTD_PATCH_DIR/femtovg`). Read from:

- `examples/nostd/README.md` (table "femtovg 0.26.0 | crates.io
  `femtovg-0.26.0` | `femtovg-0.26.0-nostd.patch` | `NOSTD_PATCH_DIR/femtovg`"; the
  patch "was checked ... and still reproduces the tree exactly", 2026-09-23);
- `examples/slint/CMakeLists.txt:43-81`: requires
  `${NOSTD_PATCH_DIR}/femtovg/Cargo.toml` and depends on `femtovg/src/*.glsl`
  (the AGL cluster sample, removed on 2026-10-19, used the same fork);
- `examples/nostd/slint-nostd.patch:129` (`femtovg = { path = "../../nostd/femtovg" }`),
  `examples/femtovg/rust/Cargo.toml.in` (`path = "@NOSTD_PATCH_DIR@/femtovg"`), and `tools/yakogl-tools/src/femtovg.rs`.

The examples' Cargo.lock files (`examples/slint/rust`, `examples/femtovg/rust`) name
femtovg by version only (it is a path crate there); the version is pinned by the patch
file name and README only.
Slint itself: `slint-ui/slint` `1007c032ca15...` plus `slint-nostd.patch`; the
femtovg renderer there only calls femtovg and adds no GLSL of its own.

## What femtovg compiles (GLES 2 context)

`MainProgram::new(context, antialias, shader_type, with_glyph_texture, no_discard, no_scissor)`
(`src/renderer/opengl/program.rs` of the fork) builds
`#version 100\n<#define EDGE_AA 1>\n` + `#define SELECT_SHADER n\n` + optional
`#define ENABLE_GLYPH_TEXTURE`, `\n#define NO_DISCARD`, `\n#define NO_SCISSOR`, then
`\n` + `main-fs.glsl` (NO_SCISSOR also replaces `float scissor = scissorMask(fpos);` by
`float scissor = 1.0;`); the vertex shader is `#version 100\n#define EDGE_AA 1\n` + `main-vs.glsl`.
`OpenGl::new_from_function_cstr` builds, per shader type (ShaderType 0..9, 7 unused):

- with glyph texture, with/without NO_DISCARD: types 0, 1, 3, 5, 8, 9;
- without glyph texture, plain: 0, 1, 2, 3, 4, 5, 6, 8, 9;
- without glyph texture, NO_DISCARD: 0, 1, 2, 3, 4, 5, 8, 9 (type 6 is built with
  `no_discard = false`, so no `texture_copy_unclipped.nodiscard`);
- NO_DISCARD + NO_SCISSOR, no glyph: 0, 1, 3, 5, 8, 9.

`antialias` is always true in Slint's use (EDGE_AA defined); the non-AA text
(no `EDGE_AA`) is never built by the samples, so it is not in the corpus.
Total: 35 fragment shaders + `main.vert` = 36 files, exactly the files present.

## How it was checked

`python3 -I tools/shaders/femtovg/verify_variants.py` regenerates all 36 files with the
rules above and compares bytes (exit 0 = identical, no missing, differing or extra file).
Result: **36 variants expected, 0 problems**. With the path of an upstream/patched
femtovg `src/renderer/opengl` as argument it takes `main-fs.glsl`/`main-vs.glsl` from there
instead (`yakogl-tools femtovg-shaders <dir>` writes the same files).

**Check against upstream (byte exact).** The crate `femtovg 0.26.0` was fetched with
`cargo fetch` (crates.io registry) and its `src/renderer/opengl/` copied to
`<femtovg-0.26.0>/upstream`. The nostd patch's `NO_DISCARD` hunk
(`main-fs.glsl`, `femtovg-0.26.0-nostd.patch` lines 590-607) was applied to that
`main-fs.glsl` (the hunk's context matched exactly once), and
`python3 -I verify_variants.py <that dir>` then reports **36 variants expected, 0
problems**: every committed file is byte for byte what the fork's assembly rules
(`femtovg-0.26.0-nostd.patch` lines 626-870) give from the real 0.26.0 sources. The
unpatched upstream `opengl.rs` has `let antialias = true;` and
`const GLSL_VERSION = "#version 100"`, so EDGE_AA is always defined and no desktop-GL
variant exists for a GLES 2 context. (An earlier cross-check from the GitHub tag through
WebFetch agreed too.) The argument-less run of the script proves only that the files agree
with each other and the rules. The committed files were generated by
`yakogl-tools femtovg-shaders` from the fork's patched tree (tools/README.md
"femtovg-shaders"), and `tools/gen_offarm.py`'s files derive from
`fill_color.nodiscard.frag`.
