Zephyr + Slint + YakoGL on a real GPU

YakoGL is an OpenGL ES 2.0 + EGL library written in Rust. It drives the GPU directly, with no Linux GPU driver underneath. So a small real-time OS like Zephyr can draw a Slint user interface on the real GPU.

The same application source runs on three boards with three different GPUs. Each board boots the demo from its own bootloader. When the demo ends, a watchdog resets the board, and it comes back to Linux.

The three boards

Raspberry Pi 4

GPU: Broadcom V3D 4.2
Panel: 1920x720
Boot: the Pi firmware (tryboot)

Toradex Verdin AM62P

GPU: Imagination PowerVR BXS-4-64
Panel: 1024x600
Boot: U-Boot (one-shot TFTP)

Toradex Verdin iMX8M Plus

GPU: Vivante GC7000UL
Panel: 1280x800
Boot: U-Boot (one-shot TFTP)

Try it in 10 minutes

This is our goal: you have a board and a Linux PC, you follow one page, and ten minutes later the demo runs on your screen. Then the board goes back to Linux by itself.

Not there yet. Today you build the image yourself, and some steps need tools from outside this repository. The Try it page lists the exact steps as they work today, and what is still missing.

What you see

  • Slint demo: a car dashboard drawn by Slint, the same picture on all three boards.
  • Cluster demo: a full instrument cluster that animates for 60 seconds and reports its frame rate.
  • Same source, same picture: one triangle test gives the same picture record on three different GPUs.
