The demo is concrete. The layer is general.

Not just Slint.
Not just Zephyr.

Slint on Zephyr is the main showcase because it makes the result visible: a modern UI, rendered by the real GPU, without a Linux GPU stack. It exercises the same OpenGL ES and EGL implementation available to other clients and platforms.

YakoGL keeps the graphics core and GPU back ends OS-independent. Platform-specific work sits behind a small OS abstraction.

A familiar API. A different stack.

Your application,
all the way
to the GPU.

YakoGL handles GPU bring-up, shader compilation and command submission. Its GPU and display drivers live alongside the graphics library.

Explore the architecture →
  1. 01

    Keep the graphics API.

    Use the standard OpenGL ES 2.0 and EGL headers. C and C++ applications link libyakogl.a; Rust applications can use the crate directly.

  2. 02

    Choose when shaders compile.

    Compile GLSL on the board, precompile your application’s shaders, or combine both. The shader guide explains the trade-offs.

  3. 03

    Inspect the whole path.

    A no_std Rust core, GPU back ends, OS abstraction and drivers in one repository. Zephyr is the tested board path; bare-metal integration is described in the build guide.
