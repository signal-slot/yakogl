OpenGL ES 2.0 on a real GPU, without a GPU driver underneath

YakoGL is an OpenGL ES 2.0 + EGL library written in Rust. It drives the GPU itself, so Zephyr (or bare metal) can draw a Slint user interface on the real GPU. The same application source runs on three boards with three different GPUs.

Conformance

The Khronos conformance tests for OpenGL ES 2.0 (dEQP-GLES2, the 17,165 cases of the mustpass list) run on Zephyr on the real GPU.

The 25 Pi 4 failures are cube-map cases that differ from the ES 2.0 reference images. The i.MX8MP warnings appear on NXP's own driver too.

Performance

glmark2-es2, on-screen, 800x600, all 33 scenes run on every board. The public reference is the same board under Linux with the vendor or Mesa driver; the conditions differ, so read it as a direction, not a contest.

BoardYakoGLPublic reference
Verdin AM62P457306.4 (TI SDK 12.01, size not stated)
Raspberry Pi 4183697 (Mesa 23.2.1, 800x600 windowed)
Verdin iMX8M Plus37382 (Vivante 6.4.11, off-screen 800x600)

Two scenes still draw wrong: terrain samples a black texture on every board, and refract misses its depth pass on the AM62P and the Pi 4. Performance work has not started; the i.MX8MP is about ten times slower than NXP's driver.
