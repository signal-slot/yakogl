Try it

Build the Slint demo on a Linux PC and boot it on your board from its own storage: the eMMC on the Verdin boards, the SD card on the Raspberry Pi 4.

1. What you need

  • One of the boards: Toradex Verdin AM62P on a Dahlia carrier, Toradex Verdin iMX8M Plus, or a Raspberry Pi 4. A panel on the board.
  • A Linux PC with Python 3, the Zephyr SDK, and Rust nightly with the aarch64-unknown-none target.

2. The workspace

python3 -m venv .venv && . .venv/bin/activate && pip install west
west init -m https://github.com/signal-slot/yakogl --mr main yakogl-ws
cd yakogl-ws && west update
pip install -r zephyr/scripts/requirements-base.txt

Zephyr comes pinned to the revision the demos run on. The no_std Slint tree the demo needs is upstream Slint plus one patch: driver/samples/zephyr/slint/nostd/README.md.

3. AM62P only: the GPU firmware

The PowerVR GPU needs Imagination's firmware, rgx.fw.36.53.104.796. It is not part of YakoGL and is never distributed with it. Take it from TI's Processor SDK for the AM62P (or from the board's /lib/firmware) under its licence, and turn it into a header:

yakogl/driver/tools/mkfwblob.sh /path/to/rgx.fw.36.53.104.796

4. Build

west build -b <board> -d build/slint yakogl/driver/samples/zephyr/slint -- \
    -DSLINT_NOSTD_DIR=<the no_std Slint tree>

<board> is verdin_am62p/am62p54/a53, verdin_imx8mp/mimx8ml8/a53 or rpi_4b. The image is build/slint/zephyr/zephyr.bin.

5. Boot it from the board's storage

Verdin boards (Torizon OS). Copy the image to /var, which is on the eMMC's first partition, then set U-Boot to load it:

scp build/slint/zephyr/zephyr.bin torizon@<board>:/tmp/
ssh torizon@<board> 'sudo cp /tmp/zephyr.bin /var/zephyr.bin && sync'
# at the U-Boot prompt, Verdin AM62P:
setenv bootcmd 'ext4load mmc 0:1 0x82000000 /ostree/deploy/torizon/var/zephyr.bin && dcache off && icache off && go 0x82000000'
saveenv
# Verdin iMX8M Plus: mmc 2:1 and 0x60000000

To go back to Linux, restore the previous bootcmd at the U-Boot prompt (printenv bootcmd before you change it).

Raspberry Pi 4. On the SD card's FAT partition, next to the Raspberry Pi firmware files, put zephyr.bin and a config.txt with kernel=zephyr.bin and arm_64bit=1. Keep the old config.txt to go back to Linux.

The full details, the panel settings and how we test on shared boards without changing their default boot are in docs/standalone-boot.md.

Known gaps

  • No demo takes touch input yet; the demos run by themselves.
  • Known defects are GitHub issues.
