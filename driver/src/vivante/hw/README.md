# Vivante register headers

`state_hi.xml.h` and `common.xml.h` are generated by the etna_viv project's
rules-ng-ng tool from its `rnndb` register descriptions (MIT licence, the notice
is in each file; the same headers ship in Mesa's `src/etnaviv/hw/` and the Linux
etnaviv driver). They are copied unchanged except for one added first line,
`/* SPDX-License-Identifier: MIT */`, which states the licence the notice in the
file already grants. More files from the same set
(`state.xml.h`, `state_3d.xml.h`, `cmdstream.xml.h`, `texdesc_3d.xml.h`) join
them when the front end, the 3D state and the shader upload are written.
